## 🚀 Projectes

### 🌍 [Travel Dashboard](https://github.com/rogercolls07/traveldashboard)

Aplicació web interactiva desenvolupada amb **JavaScript Vanilla** que proporciona als viatgers informació essencial en temps real per preparar els seus viatges.

**Funcionalitats principals:**
- 🌤️ Consulta de dades meteorològiques.
- 💱 Conversió de divises.
- 🗺️ Visualització de mapes.
- 🌎 Informació de cinc grans ciutats.

**Tecnologies:** JavaScript, HTML i CSS.

---

### 🚗 [Pràctica JavaCar](https://github.com/rogercolls07/practica-javacar-rogercolls07)

Aplicació de lloguer de vehicles desenvolupada en **Java**, amb l'objectiu de practicar els conceptes de la Programació Orientada a Objectes (POO).

El projecte treballa especialment:
- 🧩 Arquitectura i organització de classes.
- 🔗 Herència i reutilització de codi.
- 🌱 Conceptes relacionats amb la sostenibilitat.

**Tecnologia:** Java.
